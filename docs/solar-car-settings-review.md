Sevcon V3.4 explicitly documents creep torque at `291F:00` as useful for overcoming the friction needed for initial movement. Figure 27 shows a nonzero starting point in the throttle-to-torque curve. It does not document a speed threshold or timer that withdraws this torque after breakaway. Treating creep as a verified, temporary standstill boost would therefore be unsupported. [Sevcon V3.4 manual, sections 6-16 and 6-20](https://www.thunderstruck-ev.com/images/Gen4%20Product%20Manual%20V3%204.pdf)

This controller's firmware does not install `291F:00`. The supplemental dictionary's definition came from AC induction firmware and does not apply. `2911:01` still names an idling-creep priority bit, but no creep-torque setting exists for it to act on. Creep is therefore not available for breakaway assistance on this car. Leave the pedal map unchanged. No suitable automatic breakaway-only feature has been found for this firmware.

First distinguish motor shudder from smooth motor rotation with chain/freewheel catching and releasing. Also determine whether the behavior has always existed or followed motor, encoder, controller, or phase-wire changes. With the configured linear 0.5 to 4.699 V pedal map, a 0.6 V signal requests only about 2.4% normalized output. Needing more pedal to overcome static load can therefore be normal; repeated motor shudder at a steady adequate demand needs investigation.

For a controlled launch observation, record pedal voltage `2220:00`, normalized demand `2620:00`, FS1 `2123:00`, motor rpm, current demand/actual current, and fault activity. If FS1 or normalized demand chatters, address the input/interlock behavior first. If input and current demand are steady while the motor shudders, investigate encoder signal quality/alignment, phase connections, current regulation, and any fault ride-through events. If the motor rotates smoothly while drive catches mechanically, inspect the chain/freewheel engagement and torque take-up. These are diagnostic branches, not established causes. Zero neutral braking is a separate controlled trial if the input repeatedly crosses between drive and neutral; its effectiveness has not been demonstrated. The earlier suggestion to increase early pedal-map output is withdrawn because it would continue to change the response after breakaway. Do not introduce automatic torque to hide unresolved shudder.
